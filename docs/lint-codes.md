# Lint diagnostic codes

Reference list of every `code` the lint pass can report. Most codes report
`warning` or `info` severity; an `error` code prevents the question or exam
from being processed at all -- see the "Errors" table below.

The rules are derived from the `mdq` references at [exam.md] and all files at
[question-types]. They apply both to mdq-py and mdq-js. In the "Question
types" column, "any" includes exams.

| Code                                   | Severity | Question types                                           | Description                                                                                                                                                                                           |
| -------------------------------------- | -------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `accept-repeats-answer-key`            | warning  | ordering                                                 | An `accept` entry holds the same lines as the `[ordering]` block itself, once fully normalized.                                                                                                       |
| `accept-wildcard`                      | warning  | short-answer, fill-in                                    | An `accept` pattern is the `*` wildcard, which accepts every response.                                                                                                                                |
| `all-choices-correct`                  | info     | multiple-choice, multiple-selection, fill-in             | Every choice is correct (or has a `score >= 1`), so the question has no wrong answer.                                                                                                                 |
| `answer-outside-domain`                | warning  | numeric, fill-in                                         | The declared `domain` contradicts the answer's own representation (e.g. `domain: integer` with a fractional answer).                                                                                  |
| `blank-choice-comment`                 | warning  | multiple-choice, multiple-selection, true-false, fill-in | A choice's `comment` has no visible (non-whitespace) character.                                                                                                                                       |
| `blank-choice-feedback`                | warning  | multiple-choice, multiple-selection, true-false, fill-in | A choice's `feedback` has no visible (non-whitespace) character.                                                                                                                                      |
| `blank-ordering-line`                  | info     | ordering                                                 | A `lines`/`extra` entry is blank, and `skip-blanks` is not normalized, so it counts when comparing a response.                                                                                        |
| `blank-tag`                            | warning  | any                                                      | A `tags` entry is empty or whitespace only.                                                                                                                                                           |
| `blank-text-field`                     | warning  | any                                                      | A free-text metadata field (`title`, `author`, `comment`, `answerKey`) is defined but has no visible character. `preamble`/`epilogue`/`stem` use the same code as an `error` instead -- see "Errors". |
| `code-input-without-highlight`         | info     | essay                                                    | `input: code` is set but no `highlight` language is given.                                                                                                                                            |
| `domain-mismatch`                      | info     | numeric, fill-in                                         | The declared `domain` disagrees with the domain inferred from the answer and the absolute tolerance (numeric.md, "Number type/domain").                                                               |
| `duplicate-alternative-lines`          | warning  | ordering                                                 | Two `accept` entries, or two `reject` entries, hold the same lines, once fully normalized.                                                                                                            |
| `empty-include-all`                    | warning  | exam                                                     | An `include-all` adds no question: nothing matches its query, or every match is already in the exam. Reported by `Exam.resolve`, not by `load`.                                                       |
| `exam-without-questions`               | warning  | exam                                                     | The exam has no questions, so it cannot be answered.                                                                                                                                                  |
| `false-friend-true-false-marker`       | warning  | true-false                                               | Marker `S` under `locale: id` reads as true, but is the initial letter of Indonesian "salah" (false).                                                                                                 |
| `ignored-decimal-places`               | info     | numeric, fill-in                                         | `decimalPlaces` is ignored when `domain` is `integer` or `fraction`.                                                                                                                                  |
| `ignored-highlight`                    | warning  | essay, ordering                                          | `highlight` is set but ignored, since `input`/`content` is not `code`.                                                                                                                                |
| `ignored-regex-flag`                   | info     | short-answer, fill-in                                    | A `/.../flags` pattern (`regex`, or a delimited `accept`/`reject` entry) carries a flag that is accepted but has no effect.                                                                           |
| `locale-lookalike-language`            | info     | any                                                      | `locale`'s language subtag is a two-letter code that looks like a country code rather than a language (e.g. `cn` instead of `zh`).                                                                    |
| `locale-mismatched-true-false-marker`  | warning  | true-false                                               | A marker is unusual for the question's `locale`, which normally writes a different letter.                                                                                                            |
| `missing-answer-key`                   | info     | essay                                                    | `answerKey` is not defined.                                                                                                                                                                           |
| `missing-choice-id`                    | info     | multiple-choice, multiple-selection, true-false, fill-in | A choice declares no `id` of its own; one will be derived from its text.                                                                                                                              |
| `missing-id`                           | info     | any                                                      | `id` is not defined.                                                                                                                                                                                  |
| `missing-title`                        | info     | any                                                      | `title` is not defined.                                                                                                                                                                               |
| `missing-tolerance`                    | info     | numeric, fill-in                                         | No `tolerance` is given for a `decimal`/`fraction` answer, so only an exact match is accepted.                                                                                                        |
| `multiple-choice-many-correct-choices` | info     | multiple-choice, fill-in                                 | More than one choice has a `score >= 1`. A question MAY mark any number of choices as correct; this only flags the unusual case.                                                                     |
| `multiple-choice-no-correct-choice`    | info     | multiple-choice, fill-in                                 | No choice has a `score >= 1`.                                                                                                                                                                         |
| `no-correct-choice`                    | info     | multiple-selection                                       | No choice is correct, so the question has nothing to select.                                                                                                                                          |
| `non-nfc-true-false-marker`            | info     | true-false                                               | The marker is one code point, but not its own NFC form.                                                                                                                                               |
| `nonstandard-include-query`            | warning  | exam                                                     | An `include-all` query does not follow the query language docs/exam.md recommends. `Exam.resolve` adds no questions for it.                                                                           |
| `provisional-true-false-marker`        | warning  | true-false                                               | The marker is a PROVISIONAL letter: true today, but a future spec revision may reassign it.                                                                                                           |
| `redundant-regex-anchor`               | info     | short-answer, fill-in                                    | A `regex`, or a delimited `accept`/`reject` entry, writes an anchor that is already implicit: `^` without the `f` flag, `$` without the `f` or `b` flag.                                              |
| `redundant-strict-indentation`         | warning  | ordering                                                 | `indentation: "strict"` is set, but `dedent` is normalized, which flattens every line to level 0.                                                                                                     |
| `reject-without-feedback`              | info     | ordering                                                 | A `reject` entry declares no feedback, which is its whole purpose.                                                                                                                                    |
| `relative-tolerance-around-zero`       | warning  | numeric, fill-in                                         | A relative tolerance around an answer of `0` can never widen the accepted range.                                                                                                                      |
| `relative-tolerance-over-one`          | info     | numeric, fill-in                                         | A relative tolerance greater than `1` is written as a fraction, not a percentage -- likely a units mistake.                                                                                           |
| `separator-before-include`             | warning  | exam                                                     | An include block (`include` or `include-all`) is preceded by a `===` separator, which it does not need.                                                                                               |
| `shadowed-answers`                     | warning  | short-answer, fill-in                                    | `regex` takes precedence over `oneOf`, so the listed answers are never used.                                                                                                                          |
| `short-answer-not-gradable`            | warning  | short-answer, fill-in                                    | No `accept`/`oneOf`/`regex` is given and the question is not `openEnded`, so nothing can grade it.                                                                                                    |
| `stem-not-a-paragraph`                 | warning  | any                                                      | The stem starts with what looks like a heading, list, blockquote, table, or code fence rather than a paragraph.                                                                                       |
| `undeclared-id-after-include-all`      | warning  | exam                                                     | An inline question after an `include-all` declares no `id`, so its derived id changes with the questions the query adds.                                                                              |
| `unexpanded-stem-ellipsis`             | info     | any                                                      | The stem is a bare ellipsis (`...`/`…`) that was never replaced with a real statement.                                                                                                                |
| `uniform-true-false-answers`           | info     | true-false                                               | Every statement is true, or every statement is false, so there is nothing to distinguish by judgement.                                                                                                |
| `unknown-frontmatter-key`              | warning  | any                                                      | A frontmatter key is not recognized for this document/question type and was dropped.                                                                                                                  |
| `unknown-highlight-language`           | info     | essay, ordering                                          | `highlight` is not a recognized alias of a Pygments lexer.                                                                                                                                            |
| `unreachable-reject`                   | info     | short-answer, fill-in                                    | A `reject` pattern is the `*` wildcard but is not the last item, so every entry after it is never reached.                                                                                            |
| `unsafe-id`                            | warning  | any                                                      | `id` is not url-safe (`[a-zA-Z0-9]+(?:[-_][a-zA-Z0-9]+)*`).                                                                                                                                           |
| `unsplit-tag-list`                     | warning  | any                                                      | A `tags` entry contains a comma; comma-splitting only applies when `tags` is written as a single string.                                                                                              |
| `uuid-unknown-variant`                 | warning  | any                                                      | The UUID's variant nibble is not one of `8`, `9`, `a`, `b`.                                                                                                                                           |
| `uuid-unknown-version`                 | warning  | any                                                      | The UUID's version nibble is not one of `1`-`8`.                                                                                                                                                      |
| `visually-identical-choices`           | info     | multiple-choice, multiple-selection, true-false, fill-in | A choice's text renders the same as another's but is written differently in source.                                                                                                                   |
| `visually-identical-lines`             | info     | ordering                                                 | Two `lines`/`extra` entries render alike but differ in raw source; a student ordering the rendered text cannot tell them apart.                                                                       |

## Errors

These error codes prevent a question/exam object from being loaded. They do not
include parser errors, and must be checked manually either by the parser (at
some post-processing stage) or by the model validator (pydantic or zod).

| Code                                       | Question types                                           | Description                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------ | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `accept-reject-overlap`                    | ordering                                                 | An `accept` entry holds the same lines as a `reject` entry, once fully normalized.                                                                                                                                                                                                                                                 |
| `blank-choice-text`                        | multiple-choice, multiple-selection, true-false, fill-in | A choice's `text` has no visible (non-whitespace) character (multiple-choice.md, "Choices": "The choice text MUST NOT be empty").                                                                                                                                                                                                 |
| `blank-text-field`                         | any (`preamble`, `epilogue`, `stem`)                     | `preamble`, `epilogue` or `stem` is defined but has no visible character. Uses the same code as the `warning` form on `title`/`author`/`comment`/`answerKey` -- see the table above. If that turns out to be a problem, the error form uses `blank-intro-field` instead.                                                           |
| `duplicate-blank-id`                       | fill-in                                                  | Two blanks declare the same `id`.                                                                                                                                                                                                                                                                                                  |
| `duplicate-choice-id`                      | multiple-choice, multiple-selection, true-false, fill-in | Two choices (or one choice blank's choices) declare the same `id`.                                                                                                                                                                                                                                                                 |
| `duplicate-choice-text`                    | multiple-choice, multiple-selection, true-false, fill-in | Two choices' texts are the same once whitespace is normalized outside code spans.                                                                                                                                                                                                                                                  |
| `duplicate-question-id`                    | exam                                                     | Two entries of `questions` -- inline or `include` -- resolve to the same id, a declared one or the derived id (`q1`, `q2`, ...) a question with none would get.                                                                                                                                                                    |
| `forbidden-block-element`                  | any (`preamble`, `stem`, `epilogue`)                     | The field holds an H1 heading, a heading starting with `[`, a paragraph starting with `[` (except the very first paragraph of the combined preamble+stem, or when the `[` is immediately followed by `^`, the fill-in blank-marker syntax), or an unordered list whose items all start with `[` -- one of base.md's "Forbidden elements", which could be mistaken for the question body. Checked at the model level, so a `dict`/YAML/JSON document is covered too, not only one built from Markdown. |
| `invalid-regex`                            | short-answer, fill-in                                    | `regex`, or a `/`-delimited pattern in `accept`/`reject`/`preAccept`/`preReject`, does not compile as an MDQ regex.                                                                                                                                                                                                                |
| `malformed-locale`                         | any                                                      | `locale` is not a well-formed BCP 47 language tag.                                                                                                                                                                                                                                                                                 |
| `malformed-numeric-answer`                 | numeric, fill-in                                         | A string `answer` is not a valid `sign? value` (numeric.md, "Answer representation": an `INTEGER`, `DECIMAL`, or a fraction with a nonzero denominator).                                                                                                                                                                         |
| `malformed-uuid`                           | any                                                      | `uuid` is not shaped like a UUID at all. A well-formed UUID with an unusual version/variant nibble is a `warning` instead -- see `uuid-unknown-version`/`uuid-unknown-variant` in the table above.                                                                                                                                |
| `misplaced-blank`                          | fill-in                                                  | A `[^id]` marker appears outside a plain text run of the stem -- inside emphasis, a strong span, a link, image alt text, or a code span.                                                                                                                                                                                           |
| `reserved-true-false-marker`               | true-false                                               | Marker `X` is reserved for a selected multiple-selection choice and has no true/false meaning.                                                                                                                                                                                                                                     |
| `true-false-marker-disagrees-with-correct` | true-false                                               | A marker's category contradicts `correct`: a FALSE-category marker with `correct: true`, or a TRUE- or PROVISIONAL-category marker with `correct: false` -- PROVISIONAL markers represent true (true-false.md, "Body"), so they contradict `correct: false` too.                                                                |
| `undefined-blank`                          | fill-in                                                  | The stem references a `[^id]` marker that names no declared blank.                                                                                                                                                                                                                                                                 |
| `unknown-include-field`                    | exam                                                     | An `include`/`include-all` block declares a field other than `include`, or `include-all`/`max` -- exam.md, "Question and include blocks": "No other field is allowed."                                                                                                                                                           |
| `unreferenced-blank`                       | fill-in                                                  | A declared blank is never referenced by a `[^id]` marker in the stem.                                                                                                                                                                                                                                                              |

## Load errors

These codes are not rules about the document content. `load` reports them
when it cannot read the input or cannot build a model at all.

- `yaml-syntax-error`, `json-syntax-error`: the input is not valid YAML or JSON.
- `parse-error`: the Markdown source does not follow the MDQ grammar.
- `conflicting-accept`: `accept`/`reject` (or `preAccept`/`preReject`) is
  declared both in the frontmatter and as a body block (short-answer.md).
- `invalid-document`: the top level of the document is not a mapping.
- `wrong-kind`: the caller asked for a question and got an exam, or the
  reverse.
- `unresolved-include-all`: ids were requested for an exam that still holds an
  `include-all` block, which only `Exam.resolve` can expand.
