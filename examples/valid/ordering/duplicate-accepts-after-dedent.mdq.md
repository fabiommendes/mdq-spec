Ordene as linhas para ler um número e imprimir seu dobro e seu quadrado.

[ordering]
```python
n = int(input())
print(n * 2)
print(n ** 2)
```

## [accept]
```python
n = int(input())
    print(n ** 2)
print(n * 2)
```

## [accept]
```python
n = int(input())
        print(n ** 2)
print(n * 2)
```
