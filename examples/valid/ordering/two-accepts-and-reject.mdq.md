Ordene as linhas para ler três valores e imprimir o maior.

[ordering]
```python
a = int(input())
b = int(input())
c = int(input())
print(max(a, b, c))
```

## [accept]
```python
b = int(input())
a = int(input())
c = int(input())
print(max(a, b, c))
```

## [accept]
```python
c = int(input())
b = int(input())
a = int(input())
print(max(a, b, c))
```

## [reject]

> O `print` precisa vir depois das três leituras.

```python
print(max(a, b, c))
a = int(input())
b = int(input())
c = int(input())
```
