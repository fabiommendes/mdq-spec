title: Command substitution
---

In Bash, the old syntax of command substitution encloses a command in
backticks. Write the form that runs `date` and uses its output.

[short-answer]:
* `` `date` ``
  > Correct -- the backticks are part of the answer.
* `$(date)`
  > Correct -- this is the modern form.
