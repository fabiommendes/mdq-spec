# Security policy

MDQ parsers read documents that other people write. A document that makes a
parser crash, hang or use too much memory is a security problem. So is a
document that makes a renderer produce unsafe HTML.

## Supported versions

Only the latest release of each package receives security fixes.

## Report a vulnerability

Do not open a public issue. Use
[private vulnerability reporting](https://github.com/fabiommendes/mdq-spec/security/advisories/new)
on GitHub instead. Include a document that reproduces the problem and the
package version.
